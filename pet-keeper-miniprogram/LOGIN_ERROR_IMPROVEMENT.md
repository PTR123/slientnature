# 小程序登录错误提示优化说明

## ✅ 已改进

### 问题
小程序登录失败时只显示"登录失败"，没有显示具体原因。

### 改进内容

#### 1. API错误处理优化 (`utils/api.js`)

**新增详细的错误类型判断**:

```javascript
// 401 未授权
const errorMsg = res.data.error || res.data.message || '未授权，请登录'

// 400 参数错误
const errorMsg = res.data.error || '请求参数错误'

// 404 资源不存在
const errorMsg = res.data.error || '请求的资源不存在'

// 500 服务器错误
const errorMsg = res.data.error || '服务器错误，请稍后重试'

// 其他错误（包含状态码）
const errorMsg = res.data.error || res.data.message || `请求失败(${res.statusCode})`

// 网络错误
const errorMsg = err.errMsg || '网络连接失败，请检查网络设置'
```

**改进点**:
- ✅ 区分不同HTTP状态码的错误
- ✅ 显示后端返回的具体错误信息
- ✅ 移除重复的toast显示（统一在页面层显示）
- ✅ 添加详细的错误日志

---

#### 2. 登录页面错误提示优化 (`pages/login/login.js`)

**邮箱登录**:
```javascript
catch (err) {
  util.hideLoading()

  const errorMsg = err.message || '登录失败，请稍后重试'

  // 网络错误特殊处理
  if (err.errMsg && err.errMsg.includes('request:fail')) {
    util.showToast('网络连接失败，请检查网络或服务器地址')
  } else {
    util.showToast(errorMsg)
  }

  console.error('登录失败详情:', err)
}
```

**改进点**:
- ✅ 显示具体的错误原因
- ✅ 区分网络错误和业务错误
- ✅ 记录详细的错误日志到控制台
- ✅ 同样的优化应用到手机号登录和微信登录

## 🎯 现在会显示的错误类型

### 网络相关
- `网络连接失败，请检查网络或服务器地址` - 网络不通
- `请求失败(502)` - 网关错误
- `请求失败(503)` - 服务不可用
- `请求失败(504)` - 网关超时

### 业务相关
- `用户不存在` - 邮箱未注册
- `密码错误` - 密码不正确
- `请求参数错误` - 缺少必填字段
- `未授权，请登录` - Token过期或无效
- `服务器错误，请稍后重试` - 后端异常

### 用户操作
- `请输入邮箱` - 邮箱为空
- `请输入密码` - 密码为空
- `请输入正确的手机号` - 手机号格式错误
- `已取消授权` - 微信授权取消

---

## 📊 错误处理流程

```
用户操作
  ↓
登录请求
  ↓
后端响应
  ↓
├─ 200: 成功
├─ 400: 参数错误 → 显示具体错误
├─ 401: 未授权 → 显示"未授权，请登录"
├─ 404: 不存在 → 显示具体错误
├─ 500: 服务器错误 → 显示错误信息
└─ 网络错误 → 显示网络错误提示
```

## 🛠️ 调试技巧

### 查看详细错误日志

在微信开发者工具控制台中可以看到：

```
🚀 API Request: {url: "...", method: "POST", data: {...}}
❌ API Error: {statusCode: 401, data: {error: "用户不存在"}}
登录失败详情: Error: 用户不存在
```

### 常见错误排查

**1. 网络连接失败**
- 检查后端服务是否运行
- 检查小程序配置的API地址是否正确
- 检查是否配置了合法域名（生产环境）

**2. 401 未授权**
- 检查账号密码是否正确
- 检查账号是否存在
- 检查Token是否过期

**3. 500 服务器错误**
- 查看后端日志
- 检查数据库连接
- 检查后端代码是否有异常
