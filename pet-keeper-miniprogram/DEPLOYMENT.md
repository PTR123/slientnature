# 微信小程序部署指南

## 一、准备工作

### 1. 注册小程序账号

1. 访问 https://mp.weixin.qq.com/
2. 点击"立即注册" → 选择"小程序"
3. 填写账号信息：
   - 邮箱（未注册过微信公众平台）
   - 密码
   - 验证码
4. 邮箱验证
5. 信息登记：
   - 主体类型：个人/企业
   - 个人：姓名、身份证号、手机号
   - 企业：企业名称、营业执照、管理员信息
6. 完成注册

### 2. 获取 AppID

1. 登录微信公众平台
2. 开发 → 开发管理 → 开发设置
3. 复制 AppID（AppSecret 也要保存好）

### 3. 下载开发工具

访问：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

选择对应系统版本下载安装。

---

## 二、配置项目

### 1. 修改 AppID

打开 `project.config.json`，修改：

```json
{
  "appid": "你的AppID"
}
```

### 2. 配置后端地址

打开 `app.js`，修改：

```javascript
globalData: {
  apiBaseUrl: 'https://your-backend.com/api'
}
```

**重要：后端必须支持 HTTPS！**

### 3. 配置服务器域名

登录微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名

添加以下域名：

**request 合法域名：**
```
https://your-backend.com
```

**uploadFile 合法域名：**
```
https://your-backend.com
```

**downloadFile 合法域名：**
```
https://your-backend.com
```

## 三、准备图片资源

在 `images/` 目录下准备以下图片：

```
images/
├── logo.png                 # Logo (建议 200x200)
├── tab-home.png            # 首页图标 (48x48)
├── tab-home-active.png     # 首页激活 (48x48)
├── tab-species.png         # 图鉴图标 (48x48)
├── tab-species-active.png  # 图鉴激活 (48x48)
├── tab-community.png       # 社区图标 (48x48)
├── tab-community-active.png # 社区激活 (48x48)
├── tab-profile.png         # 我的图标 (48x48)
├── tab-profile-active.png  # 我的激活 (48x48)
├── default-avatar.png      # 默认头像 (100x100)
└── default-pet.png         # 默认宠物图 (200x200)
```

**图标要求：**
- 格式：PNG
- 大小：建议不超过 40KB
- 尺寸：精确或接近推荐尺寸

## 四、导入项目

### 1. 打开微信开发者工具

### 2. 导入项目

1. 点击 "+" 或 "导入项目"
2. 选择项目目录：`pet-keeper-miniprogram`
3. 填写项目名称
4. AppID：填入你的 AppID
5. 点击"导入"

### 3. 编译预览

点击工具栏的"编译"按钮，即可在模拟器中预览。

---

## 五、调试测试

### 1. 真机调试

1. 点击工具栏"真机调试"
2. 扫描二维码
3. 在手机微信中打开

**注意：**
- 真机调试需要配置服务器域名
- 或者在开发工具中勾选"不校验合法域名"

### 2. 开发调试

在开发者工具中：
- 详情 → 本地设置 → 勾选"不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书"

---

## 六、上传发布

### 1. 上传代码

1. 在开发者工具中点击"上传"
2. 填写版本号（如：1.0.0）
3. 填写项目备注
4. 点击"上传"

### 2. 设置体验版

1. 登录微信公众平台
2. 开发管理 → 开发版本
3. 找到刚上传的版本
4. 点击"选为体验版"
5. 添加体验成员（成员管理 → 项目成员）

### 3. 提交审核

**审核准备：**
- 准备截图（首页、核心功能页）
- 准备演示视频（可选）
- 填写功能说明

**提交步骤：**
1. 在开发版本中点击"提交审核"
2. 填写审核信息：
   - 功能页面类目
   - 测试账号（如需要）
   - 屏幕截图
   - 补充说明
3. 提交等待审核

### 4. 发布上线

审核通过后：
1. 收到审核通过通知
2. 登录微信公众平台
3. 点击"发布"
4. 选择发布模式：
   - 全量发布：所有用户可见
   - 灰度发布：逐步开放给用户

## 八、常见问题

### Q1: 真机预览白屏？

**解决方案：**
1. 检查服务器域名配置
2. 确认 API 支持 HTTPS
3. 在开发者工具中勾选"不校验合法域名"测试

### Q2: 图片不显示？

**解决方案：**
1. 检查图片路径是否正确
2. 确认 downloadFile 域名配置
3. 检查图片是否过大

### Q3: 登录失败？

**解决方案：**
1. 检查后端 API 地址
2. 确认后端服务正常运行
3. 查看控制台错误信息

### Q4: 审核被拒？

常见原因：
- 功能不完善
- 有测试账号密码
- 涉及未开放类目
- 界面设计问题

**解决方案：**
根据审核意见修改后重新提交。

## 九、优化建议

### 性能优化

1. **图片优化**
   - 使用 WebP 格式
   - 压缩图片质量
   - 使用 CDN

2. **代码优化**
   - 分包加载
   - 按需引入组件
   - 避免频繁 setData

3. **体验优化**
   - 添加加载提示
   - 优化网络请求
   - 使用缓存

### 功能完善

1. 添加更多页面（宠物详情、物种图鉴、社区等）
2. 实现图片上传功能
3. 添加消息通知
4. 优化用户交互
