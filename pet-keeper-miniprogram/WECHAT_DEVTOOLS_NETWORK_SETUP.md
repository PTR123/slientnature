# 微信开发者工具网络设置详细步骤

## ⚠️ 关键问题
**错误原因：微信开发者工具阻止了 HTTP 请求**

## 📋 详细操作步骤

### 步骤 1：打开设置界面

1. 在微信开发者工具右上角找到 **「详情」** 按钮
   ```
   位置：右上角工具栏
   图标：齿轮或详情图标
   ```

2. 点击后会打开设置面板

### 步骤 2：切换到本地设置

1. 在打开的设置面板中
2. 找到顶部的选项卡
3. 点击 **「本地设置」** 标签

### 步骤 3：关闭域名校验（最重要）

**必须勾选以下选项：**

```
☑️ 不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书
```

**位置示意：**
```
详情
├─ 项目配置
└─ 本地设置 ← 点这里
    ├─ 不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书 ← ☑️勾选
    ├─ 不校验安全域名、TLS 版本以及 HTTPS 证书
    └─ ...
```

### 步骤 4：重新编译

设置完成后：
1. 点击左上角 **「编译」** 按钮
2. 或按快捷键 `Cmd + B`（Mac）/ `Ctrl + B`（Windows）
3. 等待编译完成

### 步骤 5：测试网络连接

在微信开发者工具 **「控制台」** 中执行：

```javascript
// 测试后端连接
wx.request({
  url: 'http://127.0.0.1:3001/api/health',
  success(res) {
    console.log('✅ 后端连接成功:', res.data)
  },
  fail(err) {
    console.error('❌ 连接失败:', err)
  }
})
```

**成功结果：**
```
✅ 后端连接成功: {status: "ok", timestamp: "2026-04-07T..."}
```

**如果还是失败，继续下一步**

## 🔧 高级排查

### 方案 A：重启微信开发者工具

有时设置不会立即生效：

1. 完全退出微信开发者工具（Cmd + Q / Alt + F4）
2. 重新打开项目
3. 再次检查域名校验设置
4. 重新编译

### 方案 B：检查项目配置文件

查看 `project.config.json`：

```json
{
  "setting": {
    "urlCheck": false  // ← 应该是 false
  }
}
```

如果文件中没有这个配置，手动添加。

### 方案 C：使用真实 IP 地址

如果 127.0.0.1 还是不行，尝试使用本机局域网 IP：

1. 查看本机 IP：
   ```bash
   ifconfig | grep "inet " | grep -v 127.0.0.1
   ```

2. 修改 `app.js`：
   ```javascript
   apiBaseUrl: 'http://192.168.x.x:3001/api'  // 替换为你的本机IP
   ```

3. 重新编译

## 💡 常见误区

❌ **错误做法：**
- 只勾选了「项目配置」里的选项
- 修改了 `project.config.json` 但没重启工具
- 设置后没有重新编译

✅ **正确做法：**
- 在「本地设置」选项卡中勾选
- 设置后立即重新编译
- 控制台测试确认连接成功

---

## 🚨 如果还是失败

### 1. 检查后端日志

```bash
# 查看后端日志
ps aux | grep node
```

### 2. 尝试其他端口

有时端口可能被限制，修改后端端口：

```bash
# 修改后端端口为 3002
PORT=3002 npm run dev
```

然后修改小程序配置：
```javascript
apiBaseUrl: 'http://127.0.0.1:3002/api'
```

### 3. 使用代理

如果以上都不行，可以配置微信开发者工具代理：
- 设置 → 代理设置
- 选择「不使用代理」
