## 🚀 使用指南

### 1. 开发环境配置

```bash
# 1. 下载微信开发者工具
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

# 2. 导入项目
选择项目目录: /Users/mac/zrby/pet-keeper-miniprogram

# 3. 配置 AppID
使用测试号或你的 AppID

# 4. 重要配置
详情 → 本地设置 → ✅ 不校验合法域名
```

### 2. 后端配置

```javascript
// app.js 中配置后端地址
globalData: {
  apiBaseUrl: 'http://localhost:3001/api' // 本地测试
  // apiBaseUrl: 'https://your-backend.com/api' // 生产环境
}
```

### 3. 测试账号

```
邮箱: test@example.com
密码: password123
```
