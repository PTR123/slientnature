# 小程序登录错误 102 解决方案

## 错误信息
```
request:fail -102:net::ERR_CONNECTION_REFUSED
```

## 问题原因
微信小程序无法连接到后端服务器，通常是以下原因：
1. **域名校验未关闭** - 开发环境使用 HTTP，不是 HTTPS
2. **IPv6 连接问题** - localhost 可能解析到 IPv6，小程序不支持
3. **后端未启动** - 后端服务未运行

## ✅ 已修复

### 1. 强制使用 IPv4 地址
已将 `app.js` 中的 API 地址从 `localhost` 改为 `127.0.0.1`：

```javascript
globalData: {
  apiBaseUrl: 'http://127.0.0.1:3001/api' // 使用 IPv4
}
```

### 2. 后端状态确认
✅ 后端正在运行（端口 3001）
✅ 健康检查正常

## 🔧 需要您操作

### 步骤 1：微信开发者工具设置（重要）

**必须关闭域名校验：**

1. 打开微信开发者工具
2. 点击右上角 **「详情」** 按钮
3. 切换到 **「本地设置」** 选项卡
4. **勾选以下选项：**
   ```
   ☑️ 不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书
   ```

![设置位置](右上角详情-本地设置)

### 步骤 2：重新编译小程序

设置完成后，点击「编译」按钮重新加载小程序。

### 步骤 3：测试登录

在微信开发者工具控制台测试网络连接：

```javascript
wx.request({
  url: 'http://127.0.0.1:3001/api/health',
  success(res) {
    console.log('✅ 网络正常:', res.data)
  },
  fail(err) {
    console.error('❌ 网络错误:', err)
  }
})
```

**预期结果：**
```
✅ 网络正常: {status: "ok", timestamp: "..."}
```

## 💡 常见问题

**Q: 设置了不校验域名，还是报错？**

检查项：
1. 后端是否启动（`curl http://127.0.0.1:3001/api/health`）
2. 是否使用了 `127.0.0.1` 而不是 `localhost`
3. 控制台是否有更详细的错误信息
4. 微信开发者工具版本是否过旧

**Q: 为什么生产环境没问题，开发环境报错？**

原因：
- 生产环境使用 HTTPS + 合法域名
- 开发环境使用 HTTP + localhost
- 微信小程序对开发环境有特殊限制

**Q: 如何查看详细错误？**

在微信开发者工具控制台查看：
```
登录失败详情: Error: xxx
🚀 API Request: {...}
❌ API Error: {...}
```
