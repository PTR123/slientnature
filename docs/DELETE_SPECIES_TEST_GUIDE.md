# 物种管理功能测试指南

## 测试前准备

### 1. 启动服务
```bash
# 终端1：启动后端
cd pet-keeper-backend
npm run dev

# 终端2：启动前端
cd pet-keeper
npm run dev
```

### 2. 准备测试账号
- 管理员账号：需要 role 为 'admin'
- 普通用户账号：用于验证权限控制

### 3. 准备测试数据
- 至少创建3-5个测试物种
- 上传一些测试图片

## 测试步骤

### 测试1：访问管理后台
1. 访问 http://localhost:3000
2. 使用管理员账号登录
3. 导航到 `/admin` 页面
4. 点击"物种管理"标签

**预期结果：**
- ✅ 成功进入管理后台
- ✅ 看到物种管理标签页
- ✅ 显示所有物种列表

### 测试2：搜索功能
1. 在搜索框输入物种名称（如"长戟大兜虫"）
2. 观察列表过滤结果

**预期结果：**
- ✅ 列表只显示匹配的物种
- ✅ 搜索支持中文名称
- ✅ 搜索支持学名
- ✅ 清空搜索框显示所有物种

### 测试3：删除确认对话框
1. 点击某个物种的"删除"按钮
2. 查看确认对话框内容

**预期结果：**
- ✅ 弹出确认对话框
- ✅ 显示物种名称
- ✅ 提示"此操作不可撤销"
- ✅ 有"确定"和"取消"两个选项

### 测试4：取消删除
1. 点击"删除"按钮
2. 在确认对话框中点击"取消"

**预期结果：**
- ✅ 对话框关闭
- ✅ 物种未被删除
- ✅ 列表保持不变

### 测试5：成功删除
1. 选择一个要删除的物种
2. 点击"删除"按钮
3. 在确认对话框中点击"确定"

**预期结果：**
- ✅ 显示删除中状态（按钮禁用+加载动画）
- ✅ 删除成功后显示成功提示
- ✅ 列表自动刷新
- ✅ 该物种从列表中消失
- ✅ 顶部统计数据的物种数量减少

### 测试6：验证删除结果
1. 访问物种图鉴页面 `/species`
2. 搜索已删除的物种

**预期结果：**
- ✅ 物种图鉴中找不到该物种
- ✅ 直接访问详情页显示404

### 测试7：权限控制
1. 退出管理员账号
2. 使用普通用户账号登录
3. 尝试访问 `/admin` 页面

**预期结果：**
- ✅ 自动跳转到首页
- ✅ 无法访问管理后台
- ✅ 无法看到物种管理功能

### 测试8：并发删除
1. 在物种列表中同时点击多个"删除"按钮
2. 确认删除

**预期结果：**
- ✅ 每个删除操作独立进行
- ✅ 删除状态正确显示
- ✅ 所有删除操作都能完成

### 测试9：错误处理
1. 使用浏览器开发者工具
2. 在Network标签中阻止DELETE请求
3. 尝试删除物种

**预期结果：**
- ✅ 显示错误提示
- ✅ 删除按钮恢复可用状态
- ✅ 列表不受影响

### 测试10：图片显示
1. 检查物种列表中的图片

**预期结果：**
- ✅ 图片正确显示
- ✅ 图片加载失败时显示占位符
- ✅ 图片比例正确
