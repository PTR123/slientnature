```
功能：创建支付订单

响应：{ success, data: { orderId, orderNo, amount, payUrl } }
```

**POST /api/payment/mock/pay**
```

响应：{ success, order, message }
```

**GET /api/payment/status/:orderId**
```
功能：查询支付状态
响应：{ success, order }
```

**POST /api/payment/check-timeout**
```
功能：检查超时订单
响应：{ success, cancelledCount }
```

```typescript
      status: 'cancelled',
      cancelledAt: new Date()
    }
  });
```
