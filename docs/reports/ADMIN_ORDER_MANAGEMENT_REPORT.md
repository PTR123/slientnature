## 📊 API 接口使用

### 获取所有订单
```
GET /api/orders/admin/all
Headers: Authorization: Bearer {token}

Query参数：
- status: 订单状态筛选（可选）

返回：
- orders: 订单列表
- pagination: 分页信息
```

### 获取订单统计
```
GET /api/orders/admin/stats
Headers: Authorization: Bearer {token}

返回：
{
  pending: { count, amount },
  paid: { count, amount },
  shipped: { count, amount },
  completed: { count, amount },
  cancelled: { count, amount }
}
```

### 发货操作
```
POST /api/orders/admin/:id/ship
Headers: Authorization: Bearer {token}

返回：
- 更新后的订单信息
```
