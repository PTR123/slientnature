### 用户购物流程

```
1. 浏览商城 (/shop)
   ↓
2. 查看商品详情 (/shop/[id])
   ↓
3. 选择数量，加入购物车
   ↓
4. 查看购物车 (/cart)
   - 调整数量

   - 删除商品
   ↓
5. 去结算 (/checkout)
   - 填写收货信息
   - 确认订单
   ↓
6. 创建订单成功
   ↓
7. 查看订单列表 (/orders)
   - 筛选订单状态
   ↓
8. 查看订单详情 (/orders/[id])
   - 查看状态
   - 取消订单（待支付）
   - 确认收货（已发货）
```

## 📊 数据流程图

### 商品购买流程
```
用户浏览 → 选择商品 → 加入购物车 → 确认订单 → 创建订单
   ↓           ↓           ↓           ↓           ↓
商品详情   CartItem    CartItem    Order      OrderItem
  数据      数据存储    状态更新    数据生成    订单项创建
```

### 订单状态流转
```
pending (待支付)
   ↓
paid (已支付) ← 用户支付
   ↓
shipped (已发货) ← 管理员发货
   ↓
completed (已完成) ← 用户确认收货

或

pending → cancelled (已取消) ← 用户取消
```
