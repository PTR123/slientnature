## 🚀 快速开始

### 1. 登录管理后台

1. 访问 http://localhost:3000/login
2. 使用超级管理员账号登录
3. 登录后导航栏会出现 "🛡️ 管理后台" 按钮
4. 点击进入管理后台

### 2. 管理功能使用

#### 📊 概览页面
- 查看平台整体数据统计
- 了解用户增长、内容活跃度

#### 👥 用户管理
- **查看用户列表**: 显示所有注册用户
- **禁言用户**: 点击"禁言"按钮，用户将无法发帖评论
- **解禁用户**: 点击"解禁"恢复用户权限
- **设置管理员**: 点击"设为管理员"提升用户权限
- **降级管理员**: 点击"降为用户"取消管理员权限

#### 🦎 物种管理
- **添加物种**: 点击"添加物种"按钮填写详细信息
- **查看物种**: 前往物种图鉴页面查看
- **编辑/删除**: 在管理后台进行操作

#### 💬 社区管理
- **删除帖子**: 在帖子详情页，管理员可看到"删除"按钮
- **删除评论**: 在评论区域，管理员可删除不当评论

## 🔧 API 端点

### 管理员专用端点 (需要管理员权限)

```
GET    /api/admin/stats              # 获取统计数据
GET    /api/admin/users              # 获取所有用户
PATCH  /api/admin/users/:id/ban      # 禁言/解禁用户
PATCH  /api/admin/users/:id/role     # 更改用户角色
DELETE /api/admin/posts/:id          # 删除帖子
DELETE /api/admin/comments/:id       # 删除评论
PUT    /api/admin/species/:id        # 更新物种
DELETE /api/admin/species/:id        # 删除物种
```

---

## 🛡️ 安全特性

1. **权限验证**: 所有管理员端点都会验证用户角色
2. **禁言检查**: 被禁言用户无法发帖、评论
3. **自我保护**: 管理员无法禁言自己或修改自己的角色
4. **JWT 认证**: 使用 JWT Token 进行身份验证

## 📝 使用示例

### 示例 1: 禁言违规用户

1. 登录管理后台
2. 进入"用户管理"标签
3. 找到违规用户
4. 点击"禁言"按钮
5. 用户状态变为"已禁言"，无法再发布内容

### 示例 2: 添加新物种

1. 登录管理后台
2. 进入"物种管理"标签
3. 点击"添加物种"
4. 填写物种信息：
   - 名称: 豹纹守宫
   - 学名: Eublepharis macularius
   - 分类: 爬行
   - 难度: 新手友好
   - 温度: 25-30°C
   - 湿度: 60-80%
   - 等等...
5. 点击"创建物种"

### 示例 3: 删除不当帖子

1. 前往社区页面
2. 点击进入违规帖子
3. 点击"删除"按钮
4. 确认删除
