## 方案2：临时域名分享（最推荐）⭐⭐⭐⭐⭐

### 优点
- ✅ 客户可以亲自体验
- ✅ 15分钟内完成
- ✅ 完全免费
- ✅ 实时在线访问
- ✅ 不需要客户端安装任何软件

### 实施步骤

#### 选项A：使用ngrok（推荐）

**1. 安装ngrok**
```bash
# macOS
brew install ngrok

# 或下载：https://ngrok.com/download
```

**2. 启动服务**
```bash
# 启动后端API（端口3001）
cd pet-keeper-backend
npm run dev

# 启动前端（端口3000）
cd ../pet-keeper
npm run dev
```

**3. 创建临时域名**
```bash
# API临时域名
ngrok http 3001

# 输出示例：
# Forwarding  https://abc123.ngrok.io -> http://localhost:3001
# 复制这个URL：https://abc123.ngrok.io
```

```bash
# Web前端临时域名（新终端窗口）
ngrok http 3000

# 输出示例：
# Forwarding  https://xyz789.ngrok.io -> http://localhost:3000
# 复制这个URL：https://xyz789.ngrok.io
```

**4. 修改前端API配置**
```javascript
// pet-keeper/.env.local 或修改配置文件
NEXT_PUBLIC_API_URL=https://abc123.ngrok.io/api

// 重启前端
npm run dev
```

**5. 分享给客户**
```
发送给客户：
Web演示地址：https://xyz789.ngrok.io

注意事项：
- ngrok免费版URL会在8小时后失效
- 客户首次访问可能需要点击"Visit Site"按钮
- 建议在会议中同步分享，确保可用
```

#### 选项B：使用localtunnel（替代方案）

```bash
# 安装
npm install -g localtunnel

# API
lt --port 3001
# 输出：your url is: https://xyz.loca.lt

# 前端
lt --port 3000 --subdomain ziranbuyu-demo
# 输出：your url is: https://ziranbuyu-demo.loca.lt
```

#### 选项C：使用Cloudflare Tunnel（最稳定）

```bash
# 安装cloudflared
brew install cloudflare/cloudflare/cloudflared

# API隧道
cloudflared tunnel --url http://localhost:3001

# 输出：
# Your quick Tunnel has been created! Visit it at:
# https://abc-xyz.trycloudflare.com

# 前端隧道
cloudflared tunnel --url http://localhost:3000
# https://def-uvw.trycloudflare.com
```

## 方案3：快速云端部署（30分钟）⭐⭐⭐⭐

### 使用Railway + Vercel（免费）

#### 1. 部署后端API到Railway（15分钟）

```bash
# 1. 访问 railway.app
# 2. 用GitHub登录
# 3. 点击 "+ New Project"
# 4. 选择 "Deploy from GitHub repo"
# 5. 选择你的仓库
# 6. Root Directory: pet-keeper-backend
# 7. 配置环境变量：
DATABASE_URL=${{Postgres.DATABASE_URL}}
JWT_SECRET=demo-secret-key-for-client-view
# 8. 点击 Deploy
# 9. 获得 URL：https://your-api.railway.app
```

#### 2. 部署前端到Vercel（10分钟）

```bash
# 1. 访问 vercel.com
# 2. 用GitHub登录
# 3. Import Project -> 选择仓库
# 4. Root Directory: pet-keeper
# 5. Framework Preset: Next.js
# 6. 环境变量：
NEXT_PUBLIC_API_URL=https://your-api.railway.app/api
# 7. 点击 Deploy
# 8. 获得 URL：https://your-app.vercel.app
# 9. 客户可以直接访问！
```

#### 3. 分享给客户

```
Web演示地址：https://your-app.vercel.app
- 永久有效
- 自动HTTPS
- 全球CDN加速

注意：这是测试环境，功能完整但数据可能需要初始化
```

## 方案4：录制演示视频 ⭐⭐⭐⭐

### 优点
- ✅ 可以反复观看
- ✅ 专业制作，体验好
- ✅ 可以剪辑优化
- ✅ 异步分享，不受时间限制

### 实施步骤

#### 1. 准备录制工具

**推荐工具**：
- **QuickTime Player**（macOS自带，免费）
- **OBS Studio**（免费开源，功能强大）
- **录屏大师**（国产，易用）
- **ScreenFlow**（专业，付费）

#### 2. 录制内容规划

**演示视频结构**（建议10-15分钟）：

```
1. 项目介绍（1分钟）
   - 背景和目标
   - 核心价值

2. Web端演示（5分钟）
   - 登录流程
   - 首页展示
   - 核心功能：宠物管理、社区、商城
   - 用户体验亮点

3. 小程序演示（5分钟）
   - 微信登录体验
   - 首页快速加载
   - 移动端特色功能
   - 操作流畅性

4. 技术亮点（2分钟）
   - 性能优化成果
   - 数据安全保障
   - 技术架构先进性

5. 后续规划（2分钟）
   - 上线计划
   - 功能迭代
   - 服务承诺
```

#### 3. 录制技巧

```bash
# 使用QuickTime录制
1. 打开QuickTime Player
2. 文件 -> 新建屏幕录制
3. 选择录制区域（建议只录制浏览器窗口）
4. 开始录制
5. 按照演示流程操作
6. 完成后编辑和导出

# 使用OBS录制（更专业）
1. 配置场景和来源
2. 添加浏览器窗口捕获
3. 添加麦克风音频
4. 设置输出分辨率（1920x1080）
5. 开始录制
6. 后期剪辑（添加字幕、过渡效果）
```

#### 4. 添加解说

**选项A：实时解说**
- 录制时直接配音
- 自然流畅
- 但可能有口误

**选项B：后期配音**
- 录制无声视频
- 后期添加解说音频
- 可以多次录制优化

**选项C：添加字幕**
- 录制无声视频
- 后期添加文字说明
- 更专业，适合正式场合

#### 5. 分享给客户

```
视频分享方式：
1. 上传到云盘（百度网盘、腾讯微云）
   - 生成分享链接
   - 设置密码保护（可选）

2. 上传到视频平台
   - B站（可设置仅粉丝可见）
   - YouTube（可设置私密）
   - 企业视频平台

3. 直接发送文件
   - 微信发送（限制大小）
   - 邮件发送（附附件）
   - 腾讯文档/飞书文档上传
```
