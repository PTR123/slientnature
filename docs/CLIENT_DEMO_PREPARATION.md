## ⚠️ 常见问题预案

### 问题1: 服务未启动
**症状**: 浏览器无法访问 localhost:3000/3001
**解决**:
```bash
cd /Users/mac/zrby/pet-keeper-backend
npm run dev &
cd /Users/mac/zrby/pet-keeper
npm run dev &
```

### 问题2: 登录失败
**症状**: 提示密码错误或网络错误
**解决**:
1. 检查后端是否运行
2. 使用备用账号或现场注册
3. 清除浏览器缓存重试

### 问题3: 页面样式异常
**症状**: CSS未加载，页面显示混乱
**解决**:
1. 强制刷新（Ctrl+Shift+R 或 Cmd+Shift+R）
2. 检查前端构建状态
3. 清除浏览器缓存

### 问题4: 数据库无数据
**症状**: 物种列表为空
**解决**:
```bash
cd /Users/mac/zrby/pet-keeper-backend
npx tsx src/seed.ts
```
