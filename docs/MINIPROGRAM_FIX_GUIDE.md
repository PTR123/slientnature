## 🔧 修复步骤（3步解决）

### 第一步：设置开发者工具（必须！）

#### 操作步骤：
```
1. 打开微信开发者工具
2. 点击右上角"详情"按钮
3. 点击"本地设置"标签
4. 勾选以下选项：
   ☑ 不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书
```

### 第二步：清除缓存

#### 操作步骤：
```
1. 点击顶部菜单"工具"
2. 选择"清缓存"
3. 点击"清除全部缓存"
4. 点击"编译"按钮重新加载
```

### 第三步：测试连接

#### 在控制台运行测试代码：

打开控制台（Console标签），粘贴以下代码：

```javascript
wx.request({
  url: 'http://localhost:3001/api/health',
  success: (res) => {
    console.log('✅ 连接成功！', res.data);
  },
  fail: (err) => {
    console.log('❌ 连接失败！', err);
  }
});
```

**预期结果：**
```
✅ 连接成功！ {status: "ok", timestamp: "2026-04-07T..."}
```

## 📱 手机预览配置

如果需要在真机上预览，需要修改API地址：

### 步骤：
1. 获取本机IP地址
   ```bash
   # macOS
   ifconfig | grep "inet " | grep -v 127.0.0.1

   # 输出示例: inet 10.81.214.231
   ```

2. 修改 app.js
   ```javascript
   // 找到第6行，改为你的实际IP
   apiBaseUrl: 'http://10.81.214.231:3001/api'
   ```

3. 确保手机和电脑在同一WiFi网络

## 🐛 常见问题

### Q: 设置了还是失败？
```
A: 尝试以下步骤：
1. 完全关闭微信开发者工具
2. 重新打开项目
3. 再次勾选"不校验合法域名"
4. 清除全部缓存
5. 重新编译
```

### Q: 控制台显示成功但页面还是报错？
```
A: 检查代码中的API调用：
- 确认使用的是 app.globalData.apiBaseUrl
- 不要硬编码API地址
```

### Q: 后端服务确认运行中？
```bash
# 运行此命令检查
curl http://localhost:3001/api/health

# 应该返回：
{"status":"ok","timestamp":"..."}
```

## 💡 提示

### 开发环境 vs 生产环境

**开发环境：**
- 使用 HTTP
- 使用 localhost 或本地IP
- 可以不校验域名

**生产环境：**
- 必须使用 HTTPS
- 必须使用已备案域名
- 必须在微信公众平台配置域名
