## 🔧 如何在其他位置添加Logo

### 小程序添加示例

```xml
<!-- 在任何页面添加Logo -->
<image src="/images/logo.png" mode="aspectFit" class="your-logo-class"></image>

<!-- 示例CSS样式 -->
.your-logo-class {
  width: 100rpx;
  height: 100rpx;
}
```

### Web前端添加示例

```tsx
// 在React组件中
<img src="/images/logo.png" alt="自然不语" className="h-8 w-8" />
```
