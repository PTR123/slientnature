# 物种编辑表单输入框重叠问题修复

## 问题描述
物种添加页面的温度和湿度范围输入框存在重叠现象。

## 原因分析
1. 使用 `flex-1` 类导致输入框宽度不确定
2. 在窄屏幕下，输入框会压缩到最小宽度，导致重叠
3. 缺少明确的宽度限制

## 解决方案

### 修改前
```tsx
<div className="flex gap-2">
  <input className="flex-1 ..." />
  <span>-</span>
  <input className="flex-1 ..." />
</div>
```

### 修改后
```tsx
<div className="flex gap-2 items-center">
  <input className="w-24 px-3 py-2 ..." />
  <span className="text-forest-600 font-medium">-</span>
  <input className="w-24 px-3 py-2 ..." />
</div>
```

## 改进内容

### 1. 固定输入框宽度
- 使用 `w-24`（96px）替代 `flex-1`
- 确保输入框有足够的宽度显示数字
- 防止输入框被压缩

### 2. 垂直居中对齐
- 添加 `items-center` 类
- 确保输入框和 `-` 符号垂直居中
- 视觉效果更好

### 3. 优化分隔符样式
- 给 `-` 符号添加颜色 `text-forest-600`
- 添加 `font-medium` 使其更明显
- 提高可读性

### 4. 数值处理优化
- 添加 `|| 0` 防止 NaN 值
- 确保表单数据有效

## CSS类说明

| 类名 | 作用 |
|------|------|
| `w-24` | 固定宽度 6rem (96px) |
| `px-3` | 水平内边距 0.75rem |
| `py-2` | 垂直内边距 0.5rem |
| `gap-2` | 元素间距 0.5rem |
| `items-center` | 垂直居中对齐 |

## 最佳实践

1. **避免使用 flex-1 在小容器中**
   - 使用固定宽度更可靠
   - 明确的尺寸控制

2. **始终添加 items-center**
   - 确保垂直对齐
   - 提升视觉效果

3. **处理数字输入的边缘情况**
   - 使用 `|| 0` 防止 NaN
   - 验证数值范围
