# 网络连接错误修复指南 (ERR_CONNECTION_REFUSED -102)

## 当前状态验证 ✅

**已验证项目**:
- ✅ 后端服务器正常运行在端口 3001
- ✅ localhost 连接测试成功 (HTTP 200)
- ✅ 局域网IP连接测试成功 (HTTP 200)
- ✅ CORS配置正确 (允许所有来源)
- ✅ API配置正确 (`http://localhost:3001/api`)

**问题确认**: 微信开发者工具阻止了HTTP请求，不是后端问题

## 解决方案

### 方案1: 正确配置微信开发者工具 (推荐)

**必须完全关闭并重启微信开发者工具才能生效！**

#### 步骤:

1. **完全关闭微信开发者工具**
   - 右键点击Dock图标 → 退出
   - 或使用 Cmd+Q 完全退出

2. **重新打开项目**

3. **配置本地设置**
   - 点击右上角 **"详情"** 按钮
   - 选择 **"本地设置"** 标签页
   - **勾选所有"不校验"选项**:
     - ✅ 不校验合法域名、web-view(业务域名)、TLS 版本以及 HTTPS 证书
     - ✅ 不校验安全域名、TLS 版本以及 HTTPS 证书
     - ✅ 不校验业务域名、TLS 版本以及 HTTPS 证书

4. **清除缓存并重新编译**
   - 点击工具栏 **"清缓存"** → **"清除全部缓存"**
   - 点击 **"编译"** 按钮重新编译项目

5. **测试连接**
   - 进入登录页面
   - 打开调试器 Console 标签
   - 尝试登录并查看网络请求

### 方案2: 使用真实设备调试

如果模拟器仍然无法连接，使用手机扫码预览：

1. 点击工具栏 **"预览"** 按钮
2. 使用微信扫描二维码
3. 在真机上测试登录功能

**注意**: 真机调试需要在手机微信中开启开发者选项

### 方案3: 使用计算机IP地址 (备选)

如果 localhost 仍然被阻止，可以尝试使用计算机的实际IP地址：

1. 获取计算机IP地址:
   ```bash
   ifconfig | grep "inet " | grep -v 127.0.0.1
   ```

2. 修改 `pet-keeper-miniprogram/app.js`:
   ```javascript
   globalData: {
     apiBaseUrl: 'http://192.168.x.x:3001/api' // 替换为你的IP
   }
   ```

3. 重新编译并测试

**你的计算机IP地址**: `192.168.3.20`

### 方案4: 检查防火墙和安全软件

macOS 防火墙可能阻止连接：

1. 打开 **系统设置** → **隐私与安全性** → **防火墙**
2. 确保微信开发者工具允许传入连接
3. 或临时关闭防火墙测试

### 方案5: 使用网络调试工具

在微信开发者工具中启用详细日志：

1. 打开 Console
2. 输入并执行:
   ```javascript
   wx.request({
     url: 'http://localhost:3001/api/health',
     success(res) {
       console.log('✅ 连接成功:', res)
     },
     fail(err) {
       console.log('❌ 连接失败:', err)
     }
   })
   ```

## 常见错误及解决方案

### 错误 1: errno 600001
**原因**: 网络请求被阻止
**解决**: 按方案1配置微信开发者工具

### 错误 2: ERR_CONNECTION_REFUSED
**原因**: 无法连接到服务器
**检查**:
- 后端是否在运行: `curl http://localhost:3001/api/health`
- 端口是否正确: 3001

### 错误 3: net::ERR_BLOCKED_BY_CLIENT
**原因**: 浏览器扩展或安全软件阻止
**解决**: 禁用广告拦截器或安全软件
