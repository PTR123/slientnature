## 📱 功能使用指南

### 1. 登录系统
**地址**: http://localhost:3002/login

**测试账号**:
- Email: `test@example.com`
- Password: `password123`

### 2. 创建宠物档案
**路径**: 我的记录 → 创建档案

**填写内容**:
- 宠物名字
- 选择物种
- 出生日期
- 入手日期
- 照片URL（可选）

### 3. 管理宠物
**查看详情**: 点击宠物卡片
**编辑信息**: 详情页 → 编辑按钮
**删除宠物**: 详情页 → 删除按钮

### 4. 添加饲养记录
**路径**: 宠物详情页 → 添加记录

**记录类型**:
- 喂食
- 蜕皮
- 称重
- 换水
- 治疗
- 繁殖
- 其他

**可填写**:
- 日期
- 备注
- 图片URL
- 体重
- 体长

### 5. 发布社区帖子
**路径**: 社区 → 发帖

**填写内容**:
- 标题
- 内容
- 图片URL（可选）
- 标签（用逗号分隔）

### 6. 互动功能
**点赞**: 帖子详情页 → 点赞按钮
**评论**: 帖子详情页 → 评论输入框

## 📊 API 端点

### 认证
- `POST /api/auth/register` - 注册
- `POST /api/auth/login` - 登录
- `GET /api/auth/me` - 获取当前用户

### 物种
- `GET /api/species` - 获取物种列表
- `GET /api/species/:id` - 获取物种详情

### 宠物
- `GET /api/pets` - 获取宠物列表
- `POST /api/pets` - 创建宠物
- `GET /api/pets/:id` - 获取宠物详情
- `PUT /api/pets/:id` - 更新宠物
- `DELETE /api/pets/:id` - 删除宠物
- `POST /api/pets/:id/records` - 添加记录
- `GET /api/pets/:id/records` - 获取记录

### 社区
- `GET /api/posts` - 获取帖子列表
- `POST /api/posts` - 创建帖子
- `GET /api/posts/:id` - 获取帖子详情
- `DELETE /api/posts/:id` - 删除帖子
- `POST /api/posts/:id/like` - 点赞/取消点赞
- `POST /api/posts/:id/comments` - 添加评论
