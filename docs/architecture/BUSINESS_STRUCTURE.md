# 🏗️ PetKeeper 业务结构梳理

## 📊 项目概览

**项目名称**: PetKeeper - 异宠饲养管理平台
**项目类型**: 全栈 Web 应用 + 微信小程序
**核心价值**: 为异宠爱好者提供专业的饲养记录、物种知识、社区交流和商城服务

---

## 🎯 核心业务模块

### 1️⃣ 物种图鉴模块
**目标用户**: 所有用户
**核心功能**:
- 浏览异宠物种信息
- 查看饲养指南（温度、湿度、饮食等）
- 学习物种知识
- 搜索和筛选物种

**数据实体**:
- Species（物种表）

**业务价值**:
- 提供专业的饲养知识
- 帮助用户科学养宠
- 降低饲养门槛

---

### 2️⃣ 饲养记录模块
**目标用户**: 注册用户
**核心功能**:
- 创建宠物档案
- 记录饲养日志（喂食、蜕皮、称重等）
- 上传照片
- 查看历史记录

**数据实体**:
- Pet（宠物表）
- Record（记录表）

**业务价值**:
- 数字化管理宠物成长
- 数据化饲养过程
- 便于回顾和分析

---

### 3️⃣ 社区交流模块
**目标用户**: 注册用户
**核心功能**:
- 发布帖子分享经验
- 评论互动
- 点赞收藏
- 标签分类

**数据实体**:
- Post（帖子表）
- Comment（评论表）
- Like（点赞表）

**业务价值**:
- 构建异宠爱好者社区
- 知识分享和互助
- 增加用户粘性

---

### 4️⃣ 商城模块 🆕
**目标用户**: 所有用户（浏览）、注册用户（购买）、管理员（管理）
**核心功能**:

#### 用户端：
- 浏览商品
- 搜索和筛选
- 查看商品详情
- 加入购物车
- 创建订单
- 查看订单状态

#### 管理员端：
- 商品管理（上架/下架/编辑）
- 分类管理
- 订单管理
- 发货处理
- 数据统计

**数据实体**:
- Product（商品表）
- ProductCategory（分类表）
- CartItem（购物车表）
- Order（订单表）
- OrderItem（订单项表）

**业务价值**:
- 提供优质宠物用品
- 商业变现渠道
- 一站式服务平台

---

### 5️⃣ 用户管理模块
**目标用户**: 所有用户
**核心功能**:

#### 用户功能：
- 注册/登录
- 多种登录方式（邮箱、手机号、微信）
- 个人信息管理
- 头像上传

#### 管理员功能：
- 用户管理
- 权限控制
- 禁言/解禁
- 角色分配

**数据实体**:
- User（用户表）
- SmsCode（短信验证码表）

**业务价值**:
- 用户身份认证
- 权限管理
- 安全控制

## 🔄 核心业务流程

### 流程1: 新用户注册到养宠
```
1. 访问网站
2. 浏览物种图鉴（了解养什么）
3. 注册账号
4. 创建宠物档案
5. 记录饲养日志
6. 参与社区交流
```

### 流程2: 商品购买流程
```
1. 浏览商城
2. 查看商品详情
3. 加入购物车
4. 确认购买
5. 创建订单（待支付）
6. 支付订单（待实现）
7. 等待发货
8. 确认收货
9. 评价商品（待实现）
```

### 流程3: 管理员商品管理
```
1. 登录管理员账号
2. 进入管理后台
3. 创建商品分类
4. 添加商品信息
5. 上架商品
6. 处理订单
7. 发货
```

## 🏗️ 技术架构

### 前端技术栈

#### Web 端
- **框架**: Next.js 14 (App Router)
- **UI库**: React 18
- **组件库**: shadcn/ui
- **样式**: Tailwind CSS
- **状态管理**: React Context
- **认证**: JWT Token

#### 小程序端

- **语言**: JavaScript
- **样式**: WXSS

---

### 后端技术栈
- **运行时**: Node.js
- **框架**: Express.js
- **数据库**: SQLite (开发) / PostgreSQL (生产)
- **ORM**: Prisma
- **认证**: JWT
- **文件上传**: Multer

---

### 数据库设计

#### 核心表结构：

```
User（用户表）
├── id
├── email / phone / username
├── password
├── role (user/admin)
└── 关联: Pet[], Post[], Comment[], CartItem[], Order[]

Species（物种表）
├── id
├── name / scientificName
├── category
├── 饲养参数（温度、湿度等）
└── 关联: 无

Pet（宠物表）
├── id
├── name / species
├── userId
└── 关联: User, Record[]

Record（记录表）
├── id
├── type / date / notes
├── petId
└── 关联: Pet

Post（帖子表）
├── id
├── title / content / tags
├── authorId
└── 关联: User, Comment[], Like[]

Product（商品表）🆕
├── id
├── name / price / stock
├── categoryId
└── 关联: ProductCategory, CartItem[], OrderItem[]

ProductCategory（分类表）🆕
├── id
├── name / description
└── 关联: Product[]

Order（订单表）🆕
├── id
├── orderNo / status
├── userId
└── 关联: User, OrderItem[]
```

## 🌐 API 接口设计

### 认证相关 `/api/auth`
```
POST   /register          # 注册
POST   /login             # 邮箱登录
POST   /login/phone       # 手机号登录（待实现）
POST   /login/wechat      # 微信登录（待实现）
POST   /sms/send          # 发送验证码（待实现）
GET    /me                # 获取当前用户
```

### 物种相关 `/api/species`
```
GET    /                  # 获取物种列表
GET    /:id               # 获取物种详情
POST   /                  # 创建物种（管理员）
PUT    /:id               # 更新物种（管理员）
DELETE /:id               # 删除物种（管理员）
```

### 宠物相关 `/api/pets`
```
GET    /                  # 获取我的宠物
POST   /                  # 创建宠物
GET    /:id               # 获取宠物详情
PUT    /:id               # 更新宠物
DELETE /:id               # 删除宠物
```

### 社区相关 `/api/posts`
```
GET    /                  # 获取帖子列表
POST   /                  # 创建帖子
GET    /:id               # 获取帖子详情
POST   /:id/like          # 点赞
POST   /:id/comment       # 评论
```

### 商城相关 `/api/products` 🆕
```
GET    /                  # 获取商品列表
GET    /:id               # 获取商品详情
POST   /admin             # 创建商品（管理员）
PUT    /admin/:id         # 更新商品（管理员）
DELETE /admin/:id         # 删除商品（管理员）
```

### 分类相关 `/api/categories` 🆕
```
GET    /                  # 获取分类列表
POST   /admin             # 创建分类（管理员）
PUT    /admin/:id         # 更新分类（管理员）
DELETE /admin/:id         # 删除分类（管理员）
```

### 购物车相关 `/api/cart` 🆕
```
GET    /                  # 获取购物车
POST   /                  # 添加商品
PUT    /:id               # 更新数量
DELETE /:id               # 删除商品
POST   /select-all        # 全选/取消全选
```

### 订单相关 `/api/orders` 🆕
```
POST   /                  # 创建订单
GET    /                  # 获取我的订单
GET    /:id               # 获取订单详情
POST   /:id/cancel        # 取消订单
POST   /:id/complete      # 确认收货
GET    /admin/all         # 所有订单（管理员）
POST   /admin/:id/ship    # 发货（管理员）
GET    /admin/stats       # 订单统计（管理员）
```
