## 常见错误

### ERR_CONNECTION_REFUSED
- 原因：后端服务器未启动或IP地址不正确
- 解决：启动后端服务 + 检查IP配置

### request:fail url not in domain list
- 原因：开发者工具域名校验未关闭
- 解决：在详情-本地设置中勾选"不校验合法域名"

### 401 Unauthorized
- 原因：登录凭证不正确
- 解决：检查账号密码或重新注册
