# 商城图标重新设计总结

## 问题

**用户反馈**：商城的图标和社区重复了

**发现**：
- community-normal.png: 2090 bytes (2.0K)
- shop-normal.png: 2090 bytes (2.0K) ❌ **完全相同**
- community-selected.png: 2153 bytes (2.1K)
- shop-selected.png: 2153 bytes (2.1K) ❌ **完全相同**

**原因**：可能之前复制粘贴时没有修改，导致商城和社区使用了相同的图标文件。

---

## 解决方案

重新设计商城图标，改为**购物袋风格**，更符合商城功能特点。

---

## 新图标设计

### 设计风格

**购物袋造型**：
- 简洁的梯形购物袋轮廓
- U形把手设计
- 清晰的购物场景表达
- 与社区图标完全区分

### 设计参数

**尺寸**：81×81 px（小程序tabbar标准尺寸）

**颜色**：
- **Normal状态**：灰色 #8a8a8a
- **Selected状态**：绿色 #4a784a（森林绿品牌色）

**设计元素**：
```
购物袋主体：
- 梯形形状（上宽下窄）
- 左上到右上：水平线
- 左下到右下：水平线
- 左边和右边：斜线

购物袋把手：
- U形弧线
- 位于购物袋顶部
- 体现手提购物场景
```

---

## 实施过程

### 创建脚本

**文件**：`scripts/create-shop-icon.py`

**功能**：
1. 使用PIL库创建81×81图标
2. 绘制购物袋轮廓
3. Normal状态：灰色边框
4. Selected状态：绿色边框
5. 保存PNG文件

### 执行结果

```bash
python3 scripts/create-shop-icon.py

输出：
商城图标已创建完成！
- shop-normal.png: 灰色购物袋
- shop-selected.png: 绿色购物袋
```

```json
        "text": "商城",
        "iconPath": "assets/tabbar/shop-normal.png",
        "selectedIconPath": "assets/tabbar/shop-selected.png"
      }
    ]
  }
}
```

**路径**：
